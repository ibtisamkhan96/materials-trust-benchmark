Materials data trust benchmark

Can I trust this number?

Two public databases of computed materials properties were asked the same question about the same crystals. They agreed within the usual 50 meV/atom window for formation energy in 90 of 344 fair comparisons. The rest is not noise. It is different recipes, different corrections, and in some cases a different crystal hiding under the same formula.

    What this page is not

    • The live panel groups by space group. That is weaker than the CLI, which matches crystals with pymatgen StructureMatcher. Use mtb audit TiO2 when the structure identity matters.
    • 287 is a stratified sample, not a census. It over-weights correlated oxides because that is where disagreement was predicted.
    • Experimental band gaps are composition-level. Lab data has no crystal to match, so that comparison is weaker than database versus database.
    • Zero high-confidence bands is a metadata limit at OQMD, not a finding that every number is wrong.
